# Style directions — a named vocabulary for calibration

Use during Step 0/1 when the brief doesn't already dictate a visual direction: pick one named direction as the starting vocabulary, then earn the brief-specific deviation on top of it. **Picking a direction does not satisfy the genericness review in `direction.md`** — a named style answers "what family does this live in?", not "why this page, this subject?". The signature element and at least one visible deviation from the direction's stock moves still have to come from the brief.

Write the chosen direction into the design plan using the concrete, falsifiable register from `direction.md` ("Voice") — name the moves, not the mood. Cross-reference that section for writing register; it isn't duplicated here.

Palettes and pairings below are **starting points only, not verified accessible palettes** — the source stamped WCAG claims on mechanically without checking. Validate every pair per `references/color.md` before use.

**What this is, honestly**: these are named design directions with preview renders from a third-party skill repo (`bergside/awesome-design-skills`) — **not installable templates**. That source repo contains zero code files (135 `.md`, 77 `.png`, 0 `.tsx`/`.jsx`/`.html`/`.css`). A direction here is a starting vocabulary to build from by hand, never something to install or import. Preview images are the source repo's own marketing renders — useful as a mood reference, not as spec or as proof the direction is accessible.

## Tier 1 — worked directions

The ones with enough distinct craft substance to earn prose: type, color behavior, shape/radius, depth, motion tendency.

**Editorial** — fits: long-form content, magazines, publications, essays, portfolios with writing. Avoid: dashboards, dense app UI. Moves: serif display + restrained sans or serif body; strict column grid with a visible baseline rhythm; hairline rules that mark real structure; near-monochrome ink-on-paper palette, one accent; motion near zero (opacity only). Preview: [source render](https://raw.githubusercontent.com/bergside/awesome-design-skills/main/registry-examples/editorial-marketing.png).

**Warm editorial / terracotta** — the sun-baked variant: cream surfaces, ink-brown display serif, single clay accent. **This is cliché-list item 1** — reach for it only when the brief asks for warm/earthy/literary, and deviate visibly. Start: `#C56A3C` clay, `#F3E9D8` cream, DM Serif Display. Preview: [source render](https://raw.githubusercontent.com/bergside/awesome-design-skills/main/registry-examples/terracotta-marketing.png).

**Brutalism** — fits: statements, art/culture pages, anti-corporate positioning. Avoid: anything needing trust or conversion. Moves: raw system-adjacent type at jarring size jumps; unstyled-looking links; harsh asymmetric layout; default-blue-and-black or one aggressive accent; no radius, no shadows, no easing — state changes are instant. Preview: [source render](https://raw.githubusercontent.com/bergside/awesome-design-skills/main/registry-examples/brutalism-marketing.png).

**Neobrutalism** — fits: playful dev tools, indie products, event pages. Avoid: enterprise trust surfaces, long-form reading. Moves: 2–3px solid black borders; hard offset shadows (4–8px, zero blur) that grow on hover; flat vivid fills on warm off-white; small-to-zero radius; springy 150ms transform feedback. Start: `#FDC800` yellow + `#432DD7` blue-violet on `#FBFBF9`. Preview: [source render](https://raw.githubusercontent.com/bergside/awesome-design-skills/main/registry-examples/neobrutalism-marketing.png).

**Bento** — fits: feature overviews, dashboards-as-marketing, personal homepages. Avoid: linear narratives, prose-heavy pages. Moves: modular grid of mixed-size cards (spans of 1×1, 2×1, 2×2); each card one idea; consistent 12–16px radius and gap; hierarchy from card size, not type size; per-card hover lift ≤4px. Preview: [source render](https://raw.githubusercontent.com/bergside/awesome-design-skills/main/registry-examples/bento-marketing.png).

**Glassmorphism** — fits: layered hero panels over imagery, media/OS-flavored products. Avoid: text-dense UI (blur murders contrast), low-end-device audiences. Moves: translucent panels (`backdrop-blur` 12–24px, white/black at 5–15% alpha); 1px luminous inner border; needs a colorful ground beneath to read as glass; verify text contrast against the *worst* region of the backdrop. Preview: [source render](https://raw.githubusercontent.com/bergside/awesome-design-skills/main/registry-examples/glassmorphism-marketing.png).

**Neumorphism** — fits: calculator/audio-widget skeuomorph moments, single-purpose tools. Avoid: whole pages — inherently low-contrast; controls stop looking clickable. Moves: monochrome surface where elements extrude via paired light/dark soft shadows; use for one tactile control cluster at most, never for text surfaces. Preview: [source render](https://raw.githubusercontent.com/bergside/awesome-design-skills/main/registry-examples/neumorphism-marketing.png).

**Claymorphism** — fits: kids/education, friendly onboarding, playful mascot brands. Avoid: serious/financial contexts. Moves: puffy shapes, large radius (16–24px+); big soft outer shadow + lighter inner shadow for the inflated look; saturated pastels; rounded geometric sans (Poppins-class) display. Preview: [source render](https://raw.githubusercontent.com/bergside/awesome-design-skills/main/registry-examples/claymorphism-marketing.png).

**Minimal / spacious** — fits: premium products, portfolios, anything with one strong message. Avoid: content-dense surfaces that would force cramming. Moves: whitespace is the styling — section padding at the top of the scale (128–160px); ≤2 type sizes visible per viewport; near-monochrome palette, accent reserved for the single CTA; motion subtle or absent. Precision is the craft: 4px misalignments read as errors here. Preview: [minimal](https://raw.githubusercontent.com/bergside/awesome-design-skills/main/registry-examples/minimal-marketing.png) · [spacious](https://raw.githubusercontent.com/bergside/awesome-design-skills/main/registry-examples/spacious-marketing.png).

**Mono / terminal** — fits: dev tools, CLIs, infrastructure, hacker-adjacent brands. Avoid: consumer lifestyle, luxury. Moves: monospace for everything including headings; dense compact rhythm; box-drawing characters and `--flags` as structural decoration; terminal green/amber on near-black **is cliché-list item 2** — a mono direction on light ground or with an unexpected accent ages better. Start: Space Mono / JetBrains Mono. Preview: [source render](https://raw.githubusercontent.com/bergside/awesome-design-skills/main/registry-examples/mono-marketing.png).

**Risograph** — fits: events, zines, community/culture pages, playful brands. Avoid: enterprise, data-dense UI. Moves: exactly two ink colors on one warm paper ground; offset print-shadow (second color, 2–4px displaced, no blur) as the signature depth; slight grain texture; flat fills, no gradients. Start: `#F237A1` fluor pink + `#2C40A7` federal blue on off-white. Preview: [source render](https://raw.githubusercontent.com/bergside/awesome-design-skills/main/registry-examples/riso-marketing.png).

**Dithered / retro-print** — fits: retro-tech brands, game-adjacent, art projects. Avoid: accessibility-critical text surfaces. Moves: 1-bit or limited-palette dither patterns in imagery and fills; halftone gradients instead of smooth ones; pixel or bitmap display face used sparingly; body text stays a clean modern face at full contrast. Preview: [source render](https://raw.githubusercontent.com/bergside/awesome-design-skills/main/registry-examples/dithered-marketing.png).

**Hand-drawn / sketch** — fits: education, personal sites, friendly SaaS with illustration budget. Avoid: precision/trust contexts. Moves: hand-written display face (body stays legible sans); dashed or wobbly 2px outlines; pencil-textured offset shadows; paper-cream ground; doodle arrows and underlines as wayfinding. Start: `#1DAD97` teal on `#F4EDE0` cream. Preview: [doodle](https://raw.githubusercontent.com/bergside/awesome-design-skills/main/registry-examples/doodle-marketing.png) · [sketch](https://raw.githubusercontent.com/bergside/awesome-design-skills/main/registry-examples/sketch-marketing.png).

**Flat** — fits: utilitarian surfaces, icon-led products, fast-loading pages. Avoid: briefs demanding rich atmosphere. Moves: two-dimensional everything — no shadows, gradients, or textures; hierarchy purely from color blocks, size, and spacing; vivid fills at full saturation; 0–4px radius; instant or ≤150ms state changes. Preview: [source render](https://raw.githubusercontent.com/bergside/awesome-design-skills/main/registry-examples/flat-marketing.png).

**Geometric** — fits: architecture, engineering, systems products. Avoid: warm/human-centered briefs. Moves: layout derived from a visible geometric module (squares, circles, 45° diagonals); shapes as content containers; duotone or triadic palette; grid lines allowed to show; type set on the same module. Preview: [source render](https://raw.githubusercontent.com/bergside/awesome-design-skills/main/registry-examples/geometric-marketing.png).

**Skeuomorphic** — fits: audio gear, instruments, games, nostalgia plays. Avoid: general web UI (heavy, dated fast). Moves: real-material textures (leather, brushed metal, wood); controls mimic physical hardware (knobs, switches, LEDs); deep multi-layer shadows; reserve for one hero object, not whole-page chrome. Preview: [source render](https://raw.githubusercontent.com/bergside/awesome-design-skills/main/registry-examples/skeumorphism-marketing.png).

**Corporate / enterprise** — fits: B2B platforms, cloud consoles, procurement-audience pages. Avoid: briefs that need any personality risk. Moves: structured 12-col grid, generous but even spacing; one restrained brand blue + full neutral ramp; 6–8px radius; dark-theme console variant: near-black surface (`#09090b`-class), glass panels, subtle gradients, strong data hierarchy (IBM Plex family works hard here). Preview: [corporate](https://raw.githubusercontent.com/bergside/awesome-design-skills/main/registry-examples/corporate-marketing.png) · [enterprise](https://raw.githubusercontent.com/bergside/awesome-design-skills/main/registry-examples/enterprise-marketing.png).

**Vibrant** — fits: consumer apps, creator tools, youth audiences. Avoid: data-dense or trust-critical surfaces. Moves: 3–4 saturated hues given equal billing (deliberate exception to the one-accent budget — state it in the plan); chunky rounded type; color blocks as section dividers; playful hover motion (scale 1.02–1.05, 150ms). Preview: [source render](https://raw.githubusercontent.com/bergside/awesome-design-skills/main/registry-examples/vibrant-marketing.png).

**Gradient** — fits: AI/dev-tool launches, music/event pages. Avoid: defaulting to it — **purple-to-blue gradient hero is cliché-list item 4**. Moves: if gradients are the direction, commit: multi-stop mesh or grainy gradients as full-bleed grounds, not a decorative strip; pick non-default hue pairs (avoid violet→blue); text sits on a solid or heavily-scrimmed region, contrast-checked at its worst point. Preview: [source render](https://raw.githubusercontent.com/bergside/awesome-design-skills/main/registry-examples/gradient-marketing.png).

**Dramatic / theatrical** — fits: campaign pages, film/fashion, launch moments. Avoid: everyday-use tools. Moves: near-black ground, huge display type (hero >96px desktop), extreme scale contrast between display and body (ratio 1.5 top steps); one spotlight accent; choreographed entrance sequence is expected here (see `motion.md` hero band); only two weights, e.g. 400/900. Preview: [source render](https://raw.githubusercontent.com/bergside/awesome-design-skills/main/registry-examples/dramatic-marketing.png).

**Vintage / retro-tech** — fits: nostalgia products, games, personal sites. Avoid: modern-trust briefs. Moves: era commitment decides everything — pick one decade and source its actual artifacts (Win95 chrome: `#008080` teal + `#C0C0C0` silver + Silkscreen pixel type; or 70s print: mustard/avocado/burnt-orange with a rounded slab); grain/scanline texture at low opacity; body text stays modern and legible. Preview: [source render](https://raw.githubusercontent.com/bergside/awesome-design-skills/main/registry-examples/vintage-marketing.png).

**Neon** — fits: nightlife, gaming, music. Avoid: light-mode products, long reading. Moves: dark ground, 1–2 electric hues with layered `text-shadow`/`box-shadow` glow; glow reserved for the signature element only — everywhere else flat; verify glow colors' contrast as UI components (3:1). Preview: [source render](https://raw.githubusercontent.com/bergside/awesome-design-skills/main/registry-examples/neon-marketing.png).

**Research-journal mono** (source calls it `claude`) — fits: AI/research products, technical essays, thought-leadership needing gravitas without corporate polish. Avoid: playful consumer briefs, conversion funnels. Moves: near-achromatic ivory-parchment ground (never pure white) with near-black slate ink; one earthy accent held in reserve, spent on a single element; grotesque for UI chrome, serif reserved for display type on inverted dark cards; alternating ivory ↔ near-black section rhythm carries pacing instead of color; flat 0px-corner buttons except one asymmetric flat-top/rounded-bottom CTA as the signature shape; zero shadows, emphasis via underline and weight only. Preview: [source render](https://raw.githubusercontent.com/bergside/awesome-design-skills/main/registry-examples/claude-marketing.png).

**Blank-canvas mono** (source calls it `codex`) — fits: writing tools, minimal SaaS, anything wanting typography to carry all the weight. Avoid: briefs needing color-coded state or visual richness. Moves: pure black/white — black is the only fill, the only divider, and the only card surface; every interactive control is pill-shaped, image cards get a smaller precise radius for near-flat contrast against the pills; zero shadows, zero UI gradients; color enters only through photography, never through chrome. Preview: [source render](https://raw.githubusercontent.com/bergside/awesome-design-skills/main/registry-examples/codex-marketing.png).

**Exhibit / poster-immersive** (source calls it `immersive`) — fits: product tours, gamified onboarding, event/experience sites wanting a "walk-through" feel. Avoid: content-dense or reading-first pages. Moves: one continuous brand-color canvas runs the whole page — no light/dark section alternation; crisp white cards with thick black borders and hard offset shadows punch off the canvas like posters; buttons are skewed blocks whose shadow grows on hover, arcade-sign style; secondary geometric shapes in 1–2 extra brand hues add depth without breaking canvas continuity. Preview: [source render](https://raw.githubusercontent.com/bergside/awesome-design-skills/main/registry-examples/immersive-marketing.png).

**Gamified / tactile** (source calls it `lingo`, Duolingo-shaped) — fits: edtech, habit/streak apps, youth-friendly consumer products. Avoid: serious/financial or B2B contexts. Moves: one saturated signature hue (green-class) on white; big rounded-sans display type; controls read as physical buttons via a bottom-heavy solid-color 3D border that visually depresses on press; mascot/illustration budget expected; generous radius throughout, no sharp edges anywhere. Preview: [source render](https://raw.githubusercontent.com/bergside/awesome-design-skills/main/registry-examples/lingo-marketing.png).

**Dev-tool monochrome** (source calls it `shadcn`) — fits: component libraries, internal tools, technical products wanting an unbranded "serious default." Avoid: consumer/marketing pages that need a distinct personality — this is deliberately the least distinctive direction, the shared baseline half of Tier-1 SaaS already looks like. Moves: near-monochrome neutral ramp, one restrained accent; Geist/Inter-class grotesque; consistent small radius (6–8px); shadcn/ui component conventions (card, sheet, popover) rather than bespoke shapes; utility-first spacing, no ornament. Preview: [source render](https://raw.githubusercontent.com/bergside/awesome-design-skills/main/registry-examples/shadcn-marketing.png).

## Do Not

- Do not pick a direction because it's fashionable this year — fit to subject and audience, or it reads as costume.
- Do not stack two directions on one page (glassmorphism cards inside a neobrutalist layout is a component-library demo, not a design).
- Do not treat the starting palettes above as accessibility-checked — the source's WCAG annotations were stamped on mechanically and are unverified; validate per `color.md`.
- Do not let a named direction stand in for the design plan — the four-part plan and genericness review in `direction.md` still run.
- Do not use a direction's stock moves without one visible brief-specific deviation.
- Do not reach for terracotta-editorial, terminal-green-on-black, or gradient-hero without noting you are on the cliché list and justifying it from the brief.
- Do not treat a Tier 2 row as a spec to implement verbatim — it is one clause, not a plan; expand it yourself before building.
- Do not install or import anything from the source repo — it has no code, only names, descriptions, and preview renders.
